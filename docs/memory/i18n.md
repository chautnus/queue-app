# i18n — FreeQueue

## Cấu hình

- Library: **next-intl**
- Config: `src/i18n/config.ts`
- Server config: `src/i18n/request.ts`
- Provider: `src/components/LocaleProvider.tsx`

## 8 Locale hỗ trợ

| Code | Ngôn ngữ |
|------|----------|
| `en` | English (default) |
| `vi` | Tiếng Việt |
| `fr` | Français |
| `es` | Español |
| `zh` | 中文 |
| `tl` | Filipino |
| `th` | ภาษาไทย |
| `id` | Bahasa Indonesia |

## Auto-detect Logic

```ts
// src/i18n/config.ts
export function detectBrowserLocale(): string {
  // Dùng navigator.languages để detect
  // Fallback về "en" nếu không match
}
```

`LocaleProvider.tsx`:
1. Kiểm tra `localStorage.get("locale")`
2. Nếu không có → `detectBrowserLocale()`
3. Persist lựa chọn vào `localStorage`

## Locale Files

`src/i18n/locales/[lang].json` — tất cả đều có:
- `common.appName` = "FreeQueue"
- `common.all_rights`, `common.login`, etc.
- `landing.*` — landing page
- `dashboard.*` — admin dashboard
- `monitor.*` — live monitor
- `about.*`, `privacy.*`, `terms.*`
- `staff.*` — staff interface

## Namespace Usage

```tsx
const t = useTranslations("dashboard");
const tc = useTranslations("common");
// Server component: dùng getTranslations() từ next-intl/server
```

## Thêm ngôn ngữ mới

1. Thêm code vào `locales` array trong `src/i18n/config.ts`
2. Tạo `src/i18n/locales/[code].json` copy từ `en.json`
3. Dịch tất cả values
